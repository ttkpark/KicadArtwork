# nRF52840 인덕터(L1~L4) 스펙 및 선택 기준

nRF52840 레퍼런스 회로(Figure 216, Config 4)에서 사용하는 인덕터의 조건과 선택 기준을 정리합니다.

---

## 인덕터 요약표

| Designator | 값 | 용도 | 패키지 | IDC (최소 DC 전류) | 허용 오차 | 비고 |
|------------|-----|------|--------|-------------------|-----------|------|
| **L1** | 3.9nH / 4.7nH | RF 매칭 (ANT → RF 라인) | 0402 | - | ±5% | 고주파 인덕터 |
| **L2** | 10µH | RF 전원 공급 (P0.31 → VDD_nRF) | 0603 | **min = 50 mA** | ±20% | DC 전류 용량 중요 |
| **L3** | 15nH | RF 관련 전원/매칭 | 0402 | - | ±10% | 고주파 인덕터 |
| **L4** | 10µH | VEXT → VDD_HV 전원 경로 (DC/DC 입력) | 0603 | **min = 80 mA** | ±20% | **가장 중요** |

---

## IDC (DC Current / DC Bias Current)란?

**IDC = 인덕터가 견딜 수 있는 최소 DC 전류 (또는 DC Bias Current)**

- 인덕터에 DC 전류가 흐를 때, **인덕턴스 값이 떨어지지 않는 최소 전류**를 의미합니다.
- 예: "IDC, min = 80 mA" → **최소 80mA 이상의 DC 전류를 견딜 수 있어야 함**
- 실제로는 **최대 DC 전류 (Isat 또는 IDC_max)**가 더 중요하지만, 데이터시트에서는 최소 요구사항을 명시합니다.

**왜 중요한가?**
- DC/DC 컨버터나 전원 필터에서 인덕터는 **연속적으로 DC 전류가 흐릅니다**.
- 전류가 너무 크면 인덕터가 **포화(Saturation)**되어 인덕턴스가 급격히 감소하고, 필터/컨버터 성능이 저하됩니다.
- 따라서 **예상 최대 전류보다 여유 있게** 선택해야 합니다.

## 각 인덕터 상세 분석

### L1: 4.7nH (RF 매칭 인덕터)

| 항목 | 내용 |
|------|------|
| **값** | 3.9nH (v1.0) / 4.7nH (v1.1) |
| **용도** | ANT(H23) → RF 라인 직렬 연결 (RF 매칭) |
| **패키지** | 0402 |
| **IDC** | 명시 없음 (RF 신호용, DC 전류 거의 없음) |
| **허용 오차** | ±5% (정밀도 중요) |
| **타입** | High frequency chip inductor |

**작동 주파수:**
- **2.4GHz 대역** (Bluetooth Low Energy, Thread Mesh)
- SRF (Self-Resonant Frequency) 요구: **2.4GHz 이상** (작동 주파수보다 높아야 함)

**선택 기준:**
- **고주파 특성**이 중요 (2.4GHz 대역)
- Q 값(품질 계수)이 높아야 함
- SRF ≥ 3GHz 이상 권장 (여유 있게)
- DC 전류는 거의 흐르지 않으므로 IDC 조건 불필요
- 예: **Murata LQW15AN** (SRF ≈ 4~5GHz), **Coilcraft 0402CS** (SRF ≈ 5GHz)

---

### L2: 10µH (RF 전원 공급 인덕터)

| 항목 | 내용 |
|------|------|
| **값** | 10µH |
| **용도** | P0.31/AIN7 → VDD_nRF (RF 전원 공급) |
| **패키지** | 0603 |
| **IDC** | **min = 50 mA** |
| **허용 오차** | ±20% |
| **타입** | Chip inductor, IDC |

**작동 주파수:**
- **수십 MHz ~ 수백 MHz** (RF 전원 라인의 고주파 노이즈 필터링)
- RF 송신 시 발생하는 **2.4GHz 하모닉 노이즈** 필터링
- SRF 요구: **수십 MHz 이상** (작동 주파수보다 높아야 함)

**선택 기준:**
- **최소 50mA 이상의 DC 전류**를 견뎌야 함
- RF 전원 공급용이므로 **고주파 노이즈 필터링**도 중요
- SRF ≥ 50MHz 이상 권장
- 실제 전류는 RF 송신 시 수십 mA 수준
- 예: **Murata LQM18PN** (SRF ≈ 20~30MHz), **Coilcraft LPS3015** (SRF ≈ 15~25MHz)

**회로 위치:**
```
VDD_nRF ──► L2(10µH) ──► P0.31/AIN7 (RF 전원)
```

---

### L3: 15nH (RF 관련 고주파 인덕터)

| 항목 | 내용 |
|------|------|
| **값** | 15nH |
| **용도** | RF 관련 전원/매칭 (선택적) |
| **패키지** | 0402 |
| **IDC** | 명시 없음 (RF 신호용) |
| **허용 오차** | ±10% |
| **타입** | High frequency chip inductor |

**작동 주파수:**
- **2.4GHz 대역** (RF 관련 전원/매칭)
- SRF 요구: **2.4GHz 이상** (작동 주파수보다 높아야 함)

**선택 기준:**
- L1과 유사하게 **고주파 특성**이 중요
- SRF ≥ 3GHz 이상 권장
- DC 전류는 거의 없음
- 예: **Murata LQW15AN** (SRF ≈ 4~5GHz), **Coilcraft 0402CS** (SRF ≈ 5GHz)

---

### L4: 10µH (VEXT → VDD_HV 전원 경로) ⭐ **가장 중요**

| 항목 | 내용 |
|------|------|
| **값** | 10µH |
| **용도** | VEXT → VDD_HV (DC/DC 입력 필터) |
| **패키지** | 0603 |
| **IDC** | **min = 80 mA** ⚠️ |
| **허용 오차** | ±20% |
| **타입** | Chip inductor, IDC |

**선택 기준:**
- **최소 80mA 이상의 DC 전류**를 견뎌야 함
- 실제로는 **100~150mA 이상 여유** 있게 선택 권장
- DC/DC 컨버터 입력 필터이므로 **리플 전류(Ripple Current)**도 고려
- **DCR (DC Resistance)**이 낮을수록 좋음 (전력 손실 최소화)

**회로 위치:**
```
[외부 전원 3.3V/5V] ──► VEXT ──► L4(10µH) ──► VDD_HV ──► 칩 내부 DC/DC 입력
```

**작동 주파수:**
- **nRF52840 내부 DC/DC 스위칭 주파수: 약 64kHz ~ 1MHz** (칩 내부 설정)
- 일반적으로 **수십 kHz ~ 수백 kHz** 범위
- SRF 요구: **스위칭 주파수의 10배 이상** (최소 수백 kHz ~ 수 MHz)

**예상 전류:**
- nRF52840 전체 소비 전류: 약 10~50mA (일반 동작)
- RF 송신 시: 약 20~30mA 추가
- **총 예상 전류: 약 30~80mA**
- 따라서 **IDC ≥ 80mA** 조건 필요

**선택 기준 (SRF):**
- SRF ≥ 1MHz 이상 권장 (DC/DC 스위칭 주파수보다 충분히 높아야 함)
- 일반적인 10µH 인덕터의 SRF: 약 5~20MHz (충분함)

**권장 부품 예시:**
- **Murata LQM18PN10MGR** (10µH, 0603, IDC ≥ 100mA)
- **Coilcraft LPS3015-103** (10µH, 0603, IDC ≥ 150mA)
- **TDK VLS201610ET-100M** (10µH, 0603, IDC ≥ 120mA)

## 인덕터 선택 시 체크리스트

### 1. 인덕턴스 값 (L)
- ✅ L1: 4.7nH (±5%)
- ✅ L2: 10µH (±20%)
- ✅ L3: 15nH (±10%)
- ✅ L4: 10µH (±20%)

### 2. DC 전류 용량 (IDC / Isat)
- ✅ L2: **최소 50mA 이상**
- ✅ L4: **최소 80mA 이상** (권장: 100~150mA)

### 3. DC 저항 (DCR)
- ✅ 가능한 한 낮게 (전력 손실 최소화)
- 예: L4의 경우 **DCR < 1Ω** 권장

### 4. 작동 주파수 및 자체 공진 주파수 (SRF)

| 인덕터 | 작동 주파수 | SRF 요구사항 | 비고 |
|--------|------------|-------------|------|
| **L1** | 2.4GHz (RF 신호) | ≥ 3GHz 이상 권장 | RF 매칭용 |
| **L2** | 수십 MHz ~ 수백 MHz (노이즈 필터) | ≥ 50MHz 이상 권장 | RF 전원 필터 |
| **L3** | 2.4GHz (RF 신호) | ≥ 3GHz 이상 권장 | RF 관련 |
| **L4** | 수십 kHz ~ 수백 kHz (DC/DC 스위칭) | ≥ 1MHz 이상 권장 | DC/DC 입력 필터 |

**SRF (Self-Resonant Frequency)란?**
- 인덕터가 **인덕터로 동작하는 최대 주파수**
- SRF 이상에서는 인덕터가 **커패시터처럼 동작**하여 필터 성능 저하
- **작동 주파수 < SRF** 여야 함 (일반적으로 SRF가 작동 주파수의 3~10배 이상 권장)

### 5. 패키지
- ✅ L1, L3: **0402** (고주파 인덕터)
- ✅ L2, L4: **0603** (전원 인덕터, 전류 용량)

## 주의사항

1. **L4는 가장 중요**: DC/DC 입력 필터이므로 **IDC ≥ 80mA 필수**, 여유 있게 100~150mA 권장
2. **DCR 확인**: 전류가 흐르면 전압 강하 발생 → 전력 손실
3. **SRF 확인**: 자체 공진 주파수가 작동 주파수보다 충분히 높아야 함
4. **온도 특성**: 저온(-20℃)에서도 인덕턴스가 유지되는지 확인 (냉동 창고 환경)

## 작동 주파수 요약표

| 인덕터 | 값 | 작동 주파수 | SRF 요구 | IDC 요구 |
|--------|-----|------------|---------|---------|
| **L1** | 4.7nH | **2.4GHz** (RF 신호) | ≥ 3GHz | 없음 |
| **L2** | 10µH | **수십 MHz ~ 수백 MHz** (노이즈 필터) | ≥ 50MHz | ≥ 50mA |
| **L3** | 15nH | **2.4GHz** (RF 신호) | ≥ 3GHz | 없음 |
| **L4** | 10µH | **수십 kHz ~ 수백 kHz** (DC/DC 스위칭) | ≥ 1MHz | ≥ 80mA |

## 요약

- **IDC = 인덕터가 견딜 수 있는 최소 DC 전류**
- **작동 주파수**: L1/L3 = 2.4GHz, L2 = 수십 MHz, L4 = 수십 kHz
- **SRF (Self-Resonant Frequency)**: 작동 주파수보다 충분히 높아야 함 (3~10배 이상 권장)
- **L4 (10µH)**: VEXT→VDD_HV 경로, **IDC ≥ 80mA 필수** (권장: 100~150mA), SRF ≥ 1MHz
- **L2 (10µH)**: RF 전원, **IDC ≥ 50mA**, SRF ≥ 50MHz
- **L1, L3**: RF 매칭용, DC 전류 거의 없음 (IDC 조건 불필요), SRF ≥ 3GHz

SmartBox 2.0에서는 **L4를 특히 신중하게 선택**하세요. 부품 수급 시 **IDC와 SRF 조건**을 반드시 확인하시기 바랍니다.
