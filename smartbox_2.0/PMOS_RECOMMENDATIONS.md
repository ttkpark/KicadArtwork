# P-MOSFET 추천 (Load Switch용)

## 요구사항

- **용도**: 외부 장치 3.3V 전원 제어 (Load Switch)
- **전압**: 3.3V 시스템
- **전류**: 최대 500mA ~ 1A (EPD, LED 등)
- **Rds_on**: < 100mΩ (전압 강하 최소화)
- **누설 전류**: < 1nA (OFF 상태, 초저전력)
- **패키지**: SOT-23 또는 작은 패키지
- **가격**: 합리적

---

## 추천 부품 목록

### 1. Si2301DS (Vishay / Siliconix) ⭐ **최우선 추천**

**사양:**
- **Rds_on**: 120mΩ @ -4.5V, 180mΩ @ -2.5V
- **전압**: Vds = -20V, Vgs = -8V
- **전류**: Id = -2.3A (연속)
- **누설 전류**: < 1μA (Vgs = 0V)
- **패키지**: SOT-23
- **가격**: 매우 저렴 (~$0.10)

**장점:**
- ✅ 매우 저렴하고 구하기 쉬움
- ✅ SOT-23 패키지 (작고 납땜 용이)
- ✅ 충분한 전류 용량
- ✅ 일반적인 용도에 적합

**단점:**
- Rds_on이 다른 제품보다 약간 높음 (하지만 충분함)

**적용 회로:**
```
VDD_3V3 ──► Si2301DS Source
              │
              ├── Gate ──► N-MOSFET Drain
              │
              └── Drain ──► VDD_EXT
```

**구매처:** Digikey, Mouser, LCSC 등

## 최종 추천

### 일반적인 용도 (EPD, LED 등)
**1순위: Si2301DS**
- 가격 대비 성능 우수
- 구하기 쉬움

## 회로 구성 예시

### P-MOSFET + N-MOSFET 조합 (Si2301DS 사용)

```
                    VDD_3V3 (3.3V)
                       │
        ┌──────────────┼──────────────┐
        │              │              │
     [100kΩ]      Si2301DS Source [100kΩ] Pull-up
     Pull-up          │              │
        │             │              │
        └─────────────┼──────────────┘
                      │
                  Si2301DS Gate
                      │
                  BSS138 Drain (N-MOSFET)
                      │
                  BSS138 Source ──► GND
                      │
                  BSS138 Gate ──► VCC_EN (P0.25)
                      │
                  VCC_EN = HIGH → N-MOS ON → P-MOS ON → VDD_EXT = 3.3V
                  VCC_EN = LOW  → N-MOS OFF → P-MOS OFF → VDD_EXT = 0V

VDD_EXT ──► EPD_VCC
         └─► LED_VCC
         └─► TEMP_VCC
```

### 전용 Load Switch IC (TPS22915 사용)

```
VDD_3V3 ──► TPS22915 VIN
              │
              ├── EN ──► VCC_EN (P0.25)
              │
              └── VOUT ──► VDD_EXT

VCC_EN = HIGH → VDD_EXT = 3.3V
VCC_EN = LOW  → VDD_EXT = 0V
```
