# 전원 공급 분석 (XC6206PxxxMR 호환성 검토)

## 시스템 구성 요소

### 전원이 필요한 장치
1. **nRF52840 MCU**
2. **E-Paper Display** (2.13" 또는 2.9" 3-Color)
3. **RGB LED** (3개)
4. **온도 센서** (NTC 서미스터)
5. **배터리 측정 회로**

---

## XC6206PxxxMR 사양

### 출력 전류 용량
- **최소**: 60mA (XC6206P60MR 등)
- **최대**: 250mA (XC6206P250MR 등)
- **타입**: 출력 전압에 따라 다양한 전류 용량

### 전압 사양
- **입력 전압**: 1.8V ~ 6.0V
- **출력 전압**: 1.2V ~ 5.0V (0.1V 단위)
- **Dropout Voltage**: 250mV @ 100mA

---

## 각 구성 요소의 전류 소비 분석

### 1. nRF52840 MCU

| 모드 | 전류 소비 | 비고 |
|------|----------|------|
| **Deep Sleep** | ~3μA | RTC만 활성화 |
| **Active (CPU만)** | ~2mA ~ 5mA | RF 비활성화 |
| **Active + RF TX** | ~15mA ~ 20mA | RF 전송 시 |
| **Active + RF RX** | ~10mA ~ 15mA | RF 수신 시 |

**최대 전류**: ~20mA (RF 전송 시)

### 2. E-Paper Display

| 상태 | 전류 소비 | 비고 |
|------|----------|------|
| **Sleep 모드** | ~100μA ~ 500μA | 전원만 공급, 갱신 없음 |
| **갱신 중** | ~50mA ~ 100mA | 화면 갱신 시 (2~3초) |
| **SPI 통신** | ~5mA ~ 10mA | 데이터 전송 중 |

**최대 전류**: ~100mA (갱신 중)

**주의**: E-Paper는 갱신 시에만 높은 전류를 소비하며, 대부분의 시간은 Sleep 모드입니다.

### 3. RGB LED (3개)

| 상태 | 전류 소비 | 비고 |
|------|----------|------|
| **OFF** | < 1μA | GPIO Low |
| **단일 LED (50% 밝기)** | ~10mA | PWM 50% |
| **단일 LED (100% 밝기)** | ~20mA | PWM 100% |
| **3개 LED 동시 (100% 밝기)** | ~60mA | 모든 LED 최대 밝기 |

**최대 전류**: ~60mA (3개 LED 동시 최대 밝기)

### 4. 온도 센서 (NTC 서미스터)

| 상태 | 전류 소비 | 비고 |
|------|----------|------|
| **측정 중** | < 1μA | Pull-up 저항만 활성화 |
| **Sleep 모드** | < 1μA | Pull-up만 활성화 |

**최대 전류**: < 1μA (무시 가능)

### 5. 배터리 측정 회로

| 상태 | 전류 소비 | 비고 |
|------|----------|------|
| **MOSFET OFF** | < 0.1μA | Sleep 모드 |
| **측정 중** | ~500μA | ADC 활성화 (5ms) |

**최대 전류**: ~500μA (측정 중, 매우 짧은 시간)

## 권장 사항

### 전원 관리 전략

**1. E-Paper와 LED를 동시에 사용하지 않기**
- E-Paper 갱신 시: LED OFF
- LED 점멸 시: E-Paper Sleep 모드 유지
- **최대 전류: ~105mA** (E-Paper 갱신 시)

**2. Load Switch로 외부 장치 전원 제어**
- Sleep 모드: 외부 장치 전원 완전 차단
- Active 모드: 필요한 장치만 활성화
- **이미 구현됨** (VCC_EN으로 VDD_EXT 제어)

**3. 순차적 동작**
- E-Paper 갱신 → 완료 후 LED 점멸
- 또는 LED 점멸 → 완료 후 E-Paper 갱신
- **최대 전류: ~105mA**

### XC6206PxxxMR 타입 선택

**권장: XC6206P150MR 또는 XC6206P250MR**

**이유:**
- ✅ E-Paper 갱신 시 충분한 여유 (150mA 또는 250mA)
- ✅ LED 점멸 시 충분한 여유
- ✅ 순차적 동작으로 최대 105mA만 필요하지만, 여유 있게 선택

**최소 요구사항:**
- XC6206P100MR: 가능하지만 여유 없음 (경계선)
- XC6206P150MR: 권장 (여유 있음)
- XC6206P250MR: 최고 성능 (충분한 여유)

---

## 결론

### XC6206PxxxMR 호환성

**✅ 가능하지만 타입 선택 중요:**

1. **XC6206P60MR (60mA)**
   - ❌ **부족**: E-Paper 갱신 시 부족
   - 권장하지 않음

2. **XC6206P100MR (100mA)**
   - ⚠️ **경계선**: E-Paper 갱신 시 여유 없음
   - 순차적 동작 필수
   - 권장하지 않음

3. **XC6206P150MR (150mA)** ⭐ **권장**
   - ✅ **충분**: E-Paper 갱신 시 여유 있음
   - ✅ LED 점멸 시 충분
   - ✅ 순차적 동작으로 안전

4. **XC6206P250MR (250mA)** ⭐ **최고 성능**
   - ✅ **충분**: 모든 시나리오 커버 가능
   - ✅ 최악의 경우(동시 동작)도 가능
   - ✅ 최고 성능 필요 시 권장

### 전원 관리 전략

**권장 동작 시퀀스:**
1. Sleep 모드: 모든 외부 장치 전원 차단 (VCC_EN = LOW)
2. Active 모드: 필요한 장치만 순차적으로 활성화
3. E-Paper 갱신: LED OFF 상태에서만
4. LED 점멸: E-Paper Sleep 모드에서만

**이렇게 하면:**
- 최대 전류: ~105mA (E-Paper 갱신 시)
- XC6206P150MR 또는 XC6206P250MR로 충분히 커버 가능

## 최종 권장사항

**LDO 선택:**
- **1순위**: XC6206P250MR (250mA) - 최고 성능, 모든 시나리오 커버
- **2순위**: XC6206P150MR (150mA) - 권장, 충분한 여유

**전원 관리:**
- ✅ Load Switch로 외부 장치 전원 제어 (이미 구현됨)
- ✅ E-Paper와 LED 순차적 동작
- ✅ Sleep 모드에서 외부 장치 전원 완전 차단

**결론:** XC6206P150MR 또는 XC6206P250MR을 사용하면 현재 시스템을 충분히 커버할 수 있습니다! ✅
